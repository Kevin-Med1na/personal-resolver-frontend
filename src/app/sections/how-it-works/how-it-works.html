Cómo se usa

Tres pasos. Sin crear una cuenta.

  1. 1

    Elige el tipo

    Cédula para consultar a una persona; NIT para una empresa.

  2. 2

    Escribe el número

    La cédula va sin puntos. El NIT acepta puntos, espacios y dígito de verificación.

  3. 3

    Revisa el resultado

    Datos básicos y cuántas veces se ha consultado el documento con la misma información.
